## COMO DESCOBRIR TODOS OS IPS ATIVOS VIA CMD
Acesse o prompt de comando como administrador
Execute o comando IPCONFIG para identificar a faixa de IPs da rede
Execute o seguinte comando:

for /l %i in (1,1,254) do @ping A.B.C.%i -w 10 -n 1 | find "Resposta"

Substitua o A.B.C. pelos primeiros 3 numeros da faixa de IP descoberta
Por exemplo: 192.168.0 

Dessa forma, o comando fica assim:
for /l %i in (1,1,254) do @ping 192.168.0.%i -w 10 -n 1 | find "Resposta"

## RECUPERAR SENHA ROOT LINUX
- Segurar tecla SHIFT no boot
- Selecionar o primeiro item do menu e pressionar a tecla "e" para editar
- Procurar por "ro quit splash"
- Substituir por "rw init=/bin/bash"
----------
Reinicie o servidor LINUX.
Selecione a opcao de boot do Proxmox e aperte E (editar).
Ache uma linha que comece com algo como linux e que contenha quiet/splash.
Adicione no final dessa linha: init=/bin/bash ou systemd.unit=emergency.target
Da boot com essas alteracoes (normalmente Ctrl+X ou F10, conforme o sistema).
Quando entrar no shell remonte o filesystem como leitura e escrita: mount -o remount,rw /
Defina a nova senha do root: passwd root
Reinicie: reboot -f
mount -o remount,rw /
passwd root
reboot -f
